# Recommended Books & Resources: SQL & Database Querying

A curated list of authoritative books, practice platforms, documentation, and tutorials for mastering SQL query optimization and interview problem solving.

---

## 1. Essential Books

1. **SQL for Data Analysis: Advanced Techniques for Transforming Data into Insights**  
   *Author:* Cathy Tanimura  
   *Focus:* Complete guide to SQL window functions, cohort retention analysis, sessionization, text analysis, and complex data transformations.

2. **High Performance MySQL (4th Edition)**  
   *Authors:* Silvia Botros, Jeremy Tinley  
   *Focus:* In-depth coverage of MySQL query execution, B-Tree index optimization, `EXPLAIN` analysis, join algorithms, and schema indexing.

3. **PostgreSQL 16 High Performance**  
   *Authors:* Gregory Smith, Ibrar Ahmed  
   *Focus:* PostgreSQL query planner internals, parallel query execution, index types (B-Tree, GIN, GiST), and memory configuration.

---

## 2. Practice Platforms & Tutorials

* **[LeetCode SQL 50 & Top Interview 150](https://leetcode.com/studyplan/top-sql-50/)** — Canonical problem set for standard SQL interview preparation.
* **[Stratascratch](https://www.stratascratch.com/)** — Real SQL interview questions from Meta, Google, Amazon, Netflix, Uber, and Airbnb.
* **[Mode Analytics SQL Tutorial](https://mode.com/sql-tutorial/)** — Interactive guide covering basic to advanced window functions, subqueries, and data analytics.
* **[SQLZoo Interactive Tutorials](https://sqlzoo.net/)** — Hands-on SQL query practice.
