# Low-Level Design (LLD) Recommended Reading List & References

A curated list of classic books, object-oriented design references, refactoring guides, and architectural pattern catalogs for mastering Low-Level System Design (LLD) and Object-Oriented Design (OOD).

---

## 📚 Recommended Books

1. **_Design Patterns: Elements of Reusable Object-Oriented Software_** — Erich Gamma, Richard Helm, Ralph Johnson, John Vlissides (Gang of Four - GoF)
   * **Why Read It:** The foundational classic defining the 23 GoF design patterns (Creational, Structural, Behavioral). Essential reference for class design and polymorphism.

2. **_Head First Design Patterns (2nd Edition)_** — Eric Freeman & Elisabeth Robson (O'Reilly)
   * **Why Read It:** Extremely readable, visually engaging explanation of OOP principles (Encapsulation, Inheritance, Polymorphism, Abstraction) and GoF patterns (Strategy, Observer, Factory, Decorator, Adapter, Facade, Singleton, Command, Iterator, State, Proxy).

3. **_Clean Code: A Handbook of Agile Software Craftsmanship_** — Robert C. Martin (Uncle Bob)
   * **Why Read It:** Teaches naming conventions, single-responsibility functions, error handling, unit testing, and class structures essential for writing production-grade LLD code.

4. **_Clean Architecture: A Craftsman's Guide to Software Structure and Design_** — Robert C. Martin
   * **Why Read It:** In-depth exposition of the **SOLID** principles:
     * **S**ingle Responsibility Principle (SRP)
     * **O**pen/Closed Principle (OCP)
     * **L**iskov Substitution Principle (LSP)
     * **I**nterface Segregation Principle (ISP)
     * **D**ependency Inversion Principle (DIP)

5. **_Refactoring: Improving the Design of Existing Code (2nd Edition)_** — Martin Fowler
   * **Why Read It:** Catalogs code smells (Long Method, Feature Envy, Primitive Obsession) and step-by-step refactoring techniques to transform legacy code into clean, modular designs.
